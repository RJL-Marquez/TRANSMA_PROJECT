# Option A vs Option B

Both options use the same antenna and waveguide. Each site includes a 0.2 dB antenna adapter, a 0.3 dB waveguide adapter, and a 0.21 dB SMA male-male adapter.

Option A uses tilted antennas (0.1683°), as guideline Part 3, item 9 allows. Option B uses equal antenna heights.
